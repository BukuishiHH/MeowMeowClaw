# list_dir 使用指南

## 何时使用
浏览项目结构、确认文件是否存在、在读写文件之前定位路径。

## 参数
| 参数 | 必填 | 说明 |
| --- | --- | --- |
| `dir_path` | 是 | 相对工作区的目录路径; 空字符串 `""` 表示工作区根目录 |

## 输出格式
- 每个条目一行, 按名称升序排列;
- 目录名末尾带 `/`;
- 文件带字节大小, 形如 `main.py  size=1234 bytes`。

## 规则与限制
- 只列**一层**, 不递归; 需要看子目录时再次调用并传入子目录路径;
- 只能列**工作区之内**的目录, 越界会被拦截;
- 空目录返回 `目录为空`; 路径不是目录时返回 `[错误] 路径不是有效目录: <绝对路径>`。

## 示例
- 看根目录: `{"dir_path": ""}`
- 看子目录: `{"dir_path": "src"}`
