# read_file 使用指南

## 何时使用
需要查看工作区内的源代码、配置文件、文档内容时。

## 参数
| 参数 | 必填 | 说明 |
| --- | --- | --- |
| `file_path` | 是 | 相对工作区的路径, 例如 `src/main.py` |

## 规则与限制
- 只能读取**工作区之内**的文件, 越界路径会被安全拦截并返回提示;
- 文件内容超过 16000 字符会被截断, 末尾附截断提示 —— 遇到提示应改用 `list_dir` + 分段读取, 或让 `exec` 配合 `sed -n`/`head`/`tail` 取片段;
- 目标若是目录会报错, 请改用 `list_dir`。

## 示例
- 读配置: `{"file_path": "config.json"}`
- 读文档: `{"file_path": "docs/design.md"}`

## 常见错误
- 传绝对路径(如 `/etc/passwd`) -> 一律被拦截, 请用工作区相对路径;
- 文件不存在 -> 返回 `[错误] 文件不存在: <绝对路径>`, 先用 `list_dir` 确认路径。
