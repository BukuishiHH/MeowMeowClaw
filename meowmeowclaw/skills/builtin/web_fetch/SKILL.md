# web_fetch 使用指南

## 何时使用
已经拿到具体 URL, 需要阅读该网页的**详细内容**时。通常先用 `web_search` 找到链接, 再用本工具抓正文。

## 参数
| 参数 | 必填 | 说明 |
| --- | --- | --- |
| `url` | 是 | 要抓取的网页 URL, 需以 `http://` 或 `https://` 开头 |

## 行为
- 返回网页转成 Markdown 的纯文本(**保留链接**, 忽略图片);
- 跟随重定向, 使用浏览器 UA, 超时 15 秒;
- 输出超过 12000 字符会截断;
- 非 HTML(如 JSON/纯文本)会原样返回。

## 安全限制
- 只允许 `http`/`https`, 其它协议返回 `安全拦截: 只允许 http/https 协议`;
- **禁止访问本机与内网地址**(`127.0.0.1`、`localhost`、`192.168.*`、`10.*`、`169.254.*` 等), 返回 `安全拦截: 禁止访问本机/内网地址`.

## 使用建议
- 优先抓正文页而不是首页/列表页; 拿不到正文时先 `web_search` 换个链接;
- 抓取失败(HTTP 4xx/5xx)时不要反复重试同一个 URL, 换来源;
- 引用信息时把 URL 一并告诉用户, 方便核对。
