# web_search 使用指南

## 何时使用
需要**实时或最新**信息(新闻、版本号、文档变更), 或对某知识不确定需要求证时。

## 参数
| 参数 | 必填 | 默认 | 说明 |
| --- | --- | --- | --- |
| `query` | 是 | - | 搜索关键词 |
| `max_results` | 否 | 5 | 返回条数, 会被限制在 1~20 |

## 输出格式
每条结果形如:
```
### 1. 标题
链接: https://...
摘要正文
```

## 限制与注意
- 单次最多 20 条, 输出超过 8000 字符会截断;
- 搜索超时(20 秒)或网络不可用会返回 `搜索出错: ...`(此时可能是环境代理问题, 不要反复重试);
- 摘要通常不够详细: **要读正文请接着调用 `web_fetch`**;
- 无结果时返回 `未找到相关结果`, 可换关键词再试。

## 推荐流程
1. `web_search` 找到目标链接;
2. `web_fetch` 抓取该链接的正文;
3. 基于正文回答, 并给出来源链接。
