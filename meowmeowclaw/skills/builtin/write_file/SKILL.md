# write_file 使用指南

## 何时使用
新建文件, 或**整体覆盖**已有文件(修改代码、保存配置、产出文档)。

## 参数
| 参数 | 必填 | 说明 |
| --- | --- | --- |
| `file_path` | 是 | 相对工作区的目标路径, 例如 `src/new.py` |
| `content` | 是 | 要写入的完整文本内容 |

## 规则与限制
- 会**整文件覆盖**, 不是追加: 修改长文件时应先用 `read_file` 读出原文, 改好后再整体写回;
- 父目录不存在会自动创建;
- 只能写**工作区之内**的路径, 越界会被拦截;
- 目标路径是目录时报错, 不能当文件写。

## 示例
- 新建脚本: `{"file_path": "scripts/run.py", "content": "print('hi')"}`
- 覆盖配置: `{"file_path": "config.json", "content": "{...}"}`

## 常见错误
- 内容里含未转义的反斜杠/引号导致文件坏了 -> 写入后建议用 `read_file` 或 `exec` 里的语法检查确认;
- 想追加却用了本工具 -> 本工具不支持追加, 需要追加请用 `exec` 配合 `>>` 重定向。
